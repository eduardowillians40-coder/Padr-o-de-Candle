# Template de Relatório PDF

## Estrutura do Documento

### Header
- Logo da empresa (esquerda)
- Título do relatório (centro)
- Data de emissão (direita)

### Seções
1. **Sumário Executivo** - Visão geral do conteúdo
2. **Gráficos e Visualizações** - Dados em formato visual
3. **Tabelas de Dados** - Informações detalhadas
4. **Conclusões** - Análises e recomendações

### Footer
- Número da página
- Data de impressão
- Confidencialidade (se aplicável)

## Paleta de Cores
- **Primária**: #1E40AF (azul corporativo)
- **Secundária**: #F3F4F6 (cinza claro)
- **Destaque**: #059669 (verde para valores positivos)
- **Alerta**: #DC2626 (vermelho para valores negativos)
- **Texto**: #111827 (preto escuro)

## Tipografia
- **Títulos H1**: 24px, Bold, #1E40AF
- **Títulos H2**: 18px, Bold, #374151
- **Títulos H3**: 14px, SemiBold, #6B7280
- **Corpo**: 12px, Regular, #374151
- **Legendas**: 10px, Regular, #9CA3AF
